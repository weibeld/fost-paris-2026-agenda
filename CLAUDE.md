## Data update commits

After a data update (`scripts/update.py`), the commit message lists the changes compared to the data in the last commit. Check previous "Update data" commits in the Git log for the format.

- **Include:** new sessions, announced TBAs (with speakers and the number of TBAs remaining), removed sessions, and title changes
- **Leave out:** rescheduling, minor spelling changes in titles, and changes to speakers, descriptions, tracks, rooms and speaker profiles
- **Empty sections:** omit them
